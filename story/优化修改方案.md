### 修改 2/7 [P0]：修复 `mainEventLoader.js` 日志计数

**文件**：`src/loaders/mainEventLoader.js`

**现状**（L36, L85）：
```js
var mm = 0, mu = 0;
// ... mu 从未被递增 ...
logs.push("【主事件】完成: " + events.length + " (m" + mm + " u" + mu + ")");
```

**问题**：`mu` 声明但未递增。主事件 loader 对未找到表头的事件**静默创建新员工**（L60-65），而附属事件 loader 对同类情况**丢弃+计数**（subEventLoader.js:59 `su++`）。需要补充计数来对齐行为。

**修改**（2 处）：

① L60 附近，在无法匹配到 staffInfo 时递增 `mu`：
```js
// 修改前（L60-65）:
if (!staffInfo && accountId) {
  mainStaffMapResult.set(accountId, { ... });
  staffList.push({ ... });
}

// 修改后:
if (!staffInfo && accountId) {
  mu++;  // 统计从主事件新建的员工
  mainStaffMapResult.set(accountId, { ... });
  staffList.push({ ... });
}
```

② L85 日志行保持不变（`mu` 现在有实际值）。

**风险**：🟢 零风险 — 纯日志变量，不影响数据流  
**验证**：`node --check src/loaders/mainEventLoader.js`  
**回退**：`git checkout src/loaders/mainEventLoader.js`

### 修改 5/7 [P1]：`App.jsx` 添加 Error Boundary

**文件**：`src/App.jsx`

**修改**：

① 在 `export default function App()` **之前**插入 ErrorBoundary 组件：

```jsx
class ErrorBoundary extends React.Component {
  constructor(props) {
    super(props);
    this.state = { hasError: false, error: null };
  }
  static getDerivedStateFromError(error) {
    return { hasError: true, error: error };
  }
  render() {
    if (this.state.hasError) {
      return React.createElement('div', {
        style: {
          padding: '40px',
          textAlign: 'center',
          fontFamily: FONT_FAMILY_SYSTEM,
          color: COLOR_TEXT,
        }
      },
        React.createElement('div', { style: { fontSize: '32px', marginBottom: '16px' } }, '⚠️'),
        React.createElement('div', { style: { fontSize: '16px', marginBottom: '8px' } }, '插件加载失败'),
        React.createElement('div', { style: { fontSize: '12px', color: COLOR_TEXT_DIM } },
          this.state.error && this.state.error.message ? this.state.error.message : '未知错误'
        )
      );
    }
    return this.props.children;
  }
}
```

② 在 `return` 中包裹 `<ErrorBoundary>`：
```jsx
// 修改前:
return (
  <AppWrap>
    <Toolbar ... />
    <TimeCalendar ... />
    {showDebug && <DebugPanel ... />}
  </AppWrap>
);

// 修改后:
return (
  <ErrorBoundary>
    <AppWrap>
      <Toolbar ... />
      <TimeCalendar ... />
      {showDebug && <DebugPanel ... />}
    </AppWrap>
  </ErrorBoundary>
);
```

**风险**：🟡 低 — 纯新增，不修改现有逻辑。Error Boundary 是 React 16+ 标准特性。  
**注意**：使用 `React.createElement` 而非 JSX 以避免增加 Babel 编译依赖，与现有代码风格一致。  
**验证**：`node --check` + `mdye build`  
**回退**：`git checkout src/App.jsx`
