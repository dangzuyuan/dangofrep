# 方案设计文档 — 移动端触屏创建

**版本**: v2.0.0 | **日期**: 2026-05-31

---

## 1. 需求概述

**目标**：在手机/平板触屏设备上支持空白时间格长按→拖动→创建事件。移动端不复制桌面端完整拖拽（移动事件条/拉伸），改用长按+向下拖动=新建，简单可靠，不影响页面原生滚动。

**范围**：
- ✅ 长按空白时间格 ≥300ms → 激活创建模式
- ✅ 向下拖动展开色块（1 格 → 最大 8 格）
- ✅ 松手 → `onSelectSlot` 回调（与桌面框选同一回调）
- ✅ 桌面端不受任何影响
- ❌ 移动端不实现事件条拖动（移动）
- ❌ 移动端不实现事件条拉伸
- ❌ 不改变现有 Hook 逻辑

## 3. 架构设计

```
手指触摸空白时间格
  ↓ touchstart → useTouchCreate.handleTouchStart
  │  记录起始位置 + 启动 300ms 定时器
  │  （300ms 内手指移动 ≤5px → 取消，认为是滚动）
  ↓ 300ms 后定时器触发 → 激活创建模式
  │  preventDefault → 阻止页面滚动
  │  userSelect/webkitUserSelect = 'none' → 阻止文字选中
  │  setCreateState({ resourceId, startMin, endMin }) → 渲染 1 格色块
  ↓
手指向下拖动
  ↓ touchmove → 计算 dy → pixelToMinutes → slotCount = min(8, floor(dy/timejiange)+1)
  │  RAF → setCreateState → 色块实时扩展
  ↓
手指抬起
  ↓ touchend → 计算绝对时间 → onSelectSlot({ type:'CREATE', resourceId, start, end })
  │  dragHandler.onSelectSlot → 创建记录 + 打开详情
  ↓ cleanup → 色块消失 + userSelect 恢复
```

### 与桌面端的隔离

```
桌面端（鼠标）                      移动端（触屏）
  mousedown → useBoxSelect          touchstart → useTouchCreate
  mousemove → 双向框选              touchmove → 单向向下扩展
  mouseup   → onSelectSlot          touchend  → onSelectSlot（同一回调）
  ← 不影响 →                         ← 不影响 →
```

## 4. 数据流

```
用户手指操作
  ↓
useTouchCreate
  ↓ touchstart → 记录 touchRef (resourceId, startMin, containerH, totalMin)
  ↓ timer 300ms → activated → setCreateState → 1格色块
  ↓ touchmove → pixelToMinutes → slotCount (1~8)
  ↓ RAF → setCreateState({ startMin, endMin })
  ↓
TimeCalendar 重渲染
  ↓ createState.resourceId === s.id
  ↓ 渲染色块 div（蓝色半透明 + 实线边框）
  ↓
touchend
  ↓ absStart = minMinutes + startMin
  ↓ absEnd   = minMinutes + endMin
  ↓ onSelectSlot({ type:'CREATE', resourceId, start, end })
  ↓ → dragHandler.onSelectSlot → api.addWorksheetRow → openRecordInfo
  ↓ cleanup
```

## 5. 接口定义

### 5.1 新增模块

| 模块 | 导出 | 职责 |
|------|------|------|
| `useTouchCreate.js` | `useTouchCreate({ onSelectSlot, begintime, endtime, timejiange, maxSlots }) → { isCreating, createState, handleTouchStart }` | 触屏长按创建 Hook |

**参数**：

| 参数 | 类型 | 说明 |
|------|------|------|
| `onSelectSlot` | `function` | 创建回调，与桌面 useBoxSelect 共用 |
| `begintime` | `string "HH:mm"` | 时间轴起始 |
| `endtime` | `string "HH:mm"` | 时间轴结束 |
| `timejiange` | `number` | 时间格步长 |
| `maxSlots` | `number` | 最大扩展格数（默认 8） |

**返回值**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `isCreating` | `boolean` | 是否正在创建中 |
| `createState` | `{ resourceId, startMin, endMin } \| null` | 当前色块范围（偏移分钟） |
| `handleTouchStart` | `(e, resourceId) => void` | 绑定到 StaffColumn 的 onTouchStart |

### 5.2 修改组件

| 组件 | 改动 | 位置 |
|------|------|------|
| TimeCalendar.jsx | `import { useTouchCreate }` | 文件头 |
| TimeCalendar.jsx | 调用 `useTouchCreate({...})` | hooks 初始化区 |
| TimeCalendar.jsx | StaffColumn 加 `onTouchStart={...}` | JSX 渲染 |
| TimeCalendar.jsx | 加 `{isCreating && createState && ...}` 预览色块 | JSX 渲染 |
| StaffColumn.jsx | StaffColWrap 加 `touch-action: manipulation` | CSS |

## 6. 边界场景

| 场景 | 处理 |
|------|------|
| 手指按在事件条上 | `e.target.closest('[data-event-bar]')` → 跳过，不触发创建 |
| 300ms 内手指移动 >5px | 取消定时器，当作滚动 |
| 手指向上拖动（负方向） | `dy < 0` → 忽略，色块保持 1 格不变化 |
| 手指超过 8 格范围 | `Math.min(MAX_SLOTS, ...)` → 封顶 |
| 手指划出时间轴底部 | `endMin = Math.min(maxMinutes, endMin)` → 边界钳制 |
| 多指触摸 | `e.touches.length !== 1` → 跳过 |
| touchcancel（来电中断） | 强制 cleanup |
| 页面隐藏/失焦 | 强制 cleanup |
| 松手时 <1 格 | slotCount ≥ 1 始终成立（预置 1 格），正常创建 |
| 桌面端 | 无 touch 事件监听，完全不影响 |

## 8. 设计决策

| 决策 | 结论 | 理由 |
|------|------|------|
| 移动端不实现拖拽/拉伸 | 本轮不做 | 触摸拖拽与页面滚动手势冲突，需更大改动量 |
| 长按 300ms | 激活阈值 | 避免误触，与系统长按习惯一致 |
| 仅向下展开 | 单向扩展 | 简单可靠，与桌面端一致（桌面框选也可双向，但移动简化） |
| maxSlots=8 可配 | 最大格数 | 用户可配限制，避免超长事件 |
| 复用 onSelectSlot | 同一回调 | 桌面/移动创建统一走 dragHandler |
