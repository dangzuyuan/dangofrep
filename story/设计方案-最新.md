## 1. 需求概述

### 业务背景
明道云预约时间看板视图插件，通过 env 参数配置三链数据源（表头/主事件/附属事件），渲染多列资源（员工/房间）的时间排程视图。支持拖拽移动、拉伸调整、框选新建、触屏创建等交互。

### 架构目标（5 层解耦）
1. 展示层不依赖 mdye SDK，纯 Props + 回调
2. 工具函数去重统一（helpers.js 已删除，14 处重复已消除）
3. 万能字段解析/写入函数（覆盖 40+ 字段类型）
4. 适配 mdye 0.1.4 写入 API

## 4. 数据流

### 4.1 初始化数据流
```
env (31个参数) → App.jsx → useDataLoader(currentDate, refreshKey)
  → 三链并行加载 (各链独立 try/catch)
    链1 headerLoader: resolveWorksheet → getFilteredRows(全量) → staffMap
    链2 subEventLoader: resolveWorksheet → buildDateFilter → getFilteredRows(当天) → subEvents
    链3 mainEventLoader: config.worksheetId → buildDateFilter+config.filters → getFilteredRows(当天) → mainEvents
  → 合并: finalStaffMap = header ∪ main, finalEvents = main + sub
  → adaptTableViewData: adaptResources → adaptEvents → buildDepartmentTree
  → <TimeCalendar resources events departmentTree .../>
  → useAutoRefresh 注册 md_emitter 监听
```

### 4.2 拖拽写入数据流
```
用户拖拽 → useDragMove DOM 处理 → mouseup
  → onEventDrop({type:'MOVE', eventId, oldResourceId, newResourceId, newStart, newEnd})
  → dragHandler.onEventDrop:
    1. 乐观更新 events 数组(start/dur/accountId)
    2. 构造 newOldControl[{controlId, type, value}]
    3. api.updateWorksheetRow → onSaved → isSilentReload + refreshKey++ → 重新渲染
```

### 4.3 框选新建数据流
```
mousedown 空白列 → useBoxSelect.handleSelectStart
  → 记录 snapped 起点 → isSelecting=true → 虚线蓝框渲染
mousemove → pixelToMinutes → [0, totalMinutes] 钳制
  → 遇 data-event-bar 停止扩展 → RAF 更新 selectState
mouseup → snapToGrid → <1格→取消 ≥1格→onSelectSlot
  → dragHandler.onSelectSlot → 组装 controls(员工+时间+日期+时长) + 默认值字段
  → api.addWorksheetRow → onSaved + utils.openRecordInfo
```

### 4.4 点击数据流
```
mousedown → dragMovedRef=false → onDragStart(useDragMove)
mouseup(无移动) → handleBarClick(dragMovedRef=false)
  → onClick(ev) → onEventClick(ev)
  → dragHandler.onEventClick → utils.openRecordInfo({rowid})
  → 兜底: window.__openRecord(rowid)
```

### 4.5 自动刷新数据流
```
外部变更: md_emitter.fire('new-record'|'delete-record'|'update-record')
  → useAutoRefresh 捕获 → isSilentReload=true → refreshKey++
  → useDataLoader 重载 → adaptTableViewData → TimeCalendar 更新
```

### 5.5 移动重叠检测（v1.1.0-overlap）

**架构**：
```
overlapScanner.js (纯函数，零依赖)
  → useDragMove.js (mousemove 实时扫描 + mouseup 拒绝)
    → TimeCalendar.jsx (透传 isOverlapping)
      → EventBar.jsx (红色样式)
```

**scanColumnOverlap 函数签名**：
| 参数 | 类型 | 说明 |
|------|------|------|
| `resourceId` | `string` | 目标列 data-resource-id |
| `proposedStartMin` | `number` | 提议开始分钟（偏移分钟，已减 minMinutes） |
| `proposedEndMin` | `number` | 提议结束分钟（偏移分钟） |
| `excludeEventId` | `string` | 排除自身 eventId |
| `containerHeight` | `number` | 列容器高度 px |
| `totalMinutes` | `number` | 时间轴总分钟数 |

**逻辑**：`querySelectorAll('[data-event-bar]')` → 遍历每个 bar → 排除自身(eventId)和背景(isBackground) → 比较时间区间 → 任一个重叠返回 true。

**关键教训**：传入 scanColumnOverlap 的分钟必须是**偏移分钟**（`newStartMin - minMinutes`），不是绝对分钟。任何 `pixelToMinutes` 调用方遵循此规则。

### 5.6 移动端触屏创建（v2.0.0）

**流程**：
```
touchstart → 记录起始位置 + 300ms 定时器
  ↓ 300ms 内移动 ≤5px → 取消（认为是滚动）
300ms 后定时器触发 → 激活创建模式 → 1格色块
touchmove → pixelToMinutes → slotCount = min(8, floor(dy/timejiange)+1) → 色块扩展
touchend → snapToGrid → onSelectSlot({type:'CREATE', ...}) → dragHandler.onSelectSlot
```

**useTouchCreate 参数**：`{ onSelectSlot, begintime, endtime, timejiange, maxSlots=8 }`
**返回值**：`{ isCreating, createState, handleTouchStart }`

**边界处理**：
- 手指按在事件条上（`e.target.closest('[data-event-bar]')`）→ 跳过
- 300ms 内移动 >5px → 取消定时器，当滚动
- 向上拖动 dy<0 → 忽略，色块保持 1 格
- 多指触摸 `e.touches.length !== 1` → 跳过

## 6. 数据格式定义

### 6.1 R5 中间格式（loaders → adapters）

**staffMap**：
```
Map<accountId, { accountId, rowid, name, departmentId, departmentName }>
```

**events**（无 colIdx）：
```
[{ rowid, accountId, start:"HH:mm", dur:number, title, color, fc, type:"main"|"sub" }]
```

### 6.2 TimeCalendar 标准格式

**Resource**: `{ id, accountId, name, rowid?, departmentId, departmentName }`
**Event**: `{ id, resourceId, startTime:"HH:mm:ss", endTime:"HH:mm:ss", title, color, fontColor?, isBackground, _rowid, _type }`
**Department**: `{ id, name, children: Resource[] }`

### 6.3 回调参数格式

```
onEventClick: (event | null) => void
onEventDrop: ({ type:'MOVE', eventId, oldResourceId, newResourceId, newStart:"HH:mm:ss", newEnd:"HH:mm:ss" }) => void
```

## 11. 边界场景 & 异常处理

### 11.1 数据边界
| 场景 | 处理 |
|------|------|
| 无表头 | staffMap 为空 → resources=[] → "暂无人员数据" |
| 无主事件 | events=[] → 每列"暂无安排" → Toolbar 计数 0 |
| 无附属事件 | subDate+subBegin 为空 → 跳过链2 |
| 无视图/openview | getViews 三层降级 |
| 参数缺省 | App.jsx 常量兜底 |
| 事件超出时间范围 | `getEventPosition` 钳制 (v5.3.0) |
| 链加载失败 | 独立 try/catch，仅 addLog，不阻断其他链 |
| 加载锁 | loadingRef 防 React StrictMode 并发 |
| 拖拽 API 失败 | .catch → 界面不刷新（乐观更新已生效，下次刷新恢复） |
| 点击 vs 拖拽 | dragMovedRef + 5px 阈值 |
| CSS 变量颜色 | VAR_COLOR_MAP 映射 → COLOR_PALETTE 回退 |
| 8位 hex | 截断 `#1677ffff`→`#1677ff` |

### 11.2 历史 Bug 教训

**BUG-001: 列体表头错位**
- 根因：`buildDepartmentTree` 按 `departmentId`(UUID) 排序，`headerLoader` 按 `departmentName`(拼音) 排序 → 列体与表头部门顺序不一致
- 修复：1 行 `a.name.localeCompare(b.name, "zh")` 替代 `a.id.localeCompare(b.id)`
- 教训：多个模块各自排序必须用同一键

**移动重叠检测坐标系统 Bug**（修复 2 次）
- 根因：`pixelToMinutes(rect, ...)` 返回偏移分钟 [0, totalMinutes]，但调用方传入绝对分钟
- 修复：`newStartMin - minMinutes` 入参（移动），`- minMinutes` 入 + `+ minMinutes` 出（拉伸）
- 教训：任何涉及 pixelToMinutes 的地方，入参必须是偏移分钟

**松手弹回闪烁**（发现 2 次: move 已修 → resize 再犯）
- 修复模式：ref 先清 → state 延迟清 (setTimeout 2000)
- 两个 Hook (useDragMove/useDragResize) 共享此模式，一个改了另一个没跟 → 弹回复发
- 教训：两个 Hook 的 mouseup cleanup 必须同步修改

**文本选中残留、重复 DOM 属性、死代码残留** — 详见 `story/方案设计-移动重叠检测.md` §10。

## 14. 关键设计决策（ADR）

| 决策 | 结论 | 理由 |
|------|------|------|
| 解耦边界 | = src/timeline/ 目录 | grep 可自动验证 |
| 工具函数不合并 | parseParam/parseField/mdyeApi 保持独立 | 单一职责、可独立测试 |
| adapters 独立层 | loaders 和 TimeCalendar 之间加翻译层 | 换展示时只改 adapters |
| onMouseUp+dragMovedRef | 替代 onClick | 不依赖浏览器 click 生成 |
| window.__openRecord | 全局兜底函数 | onClick 链不稳定时的保底 |
| 乐观更新+松手不复位 | dragHandler 先改 events 再调 API | 防止视觉弹回 |
| buildDepartmentTree 排序 | 按 departmentName 拼音 | 与 headerLoader 排序一致 |
| 移动端不实现拖拽/拉伸 | 仅触屏创建 | 触屏拖拽与页面滚动手势冲突 |
| 两份 constants.js 不合并 | 展示层/业务层各自维护 | R1 解耦：展示层不 import 业务层 |

### A1 框选坐标系
```
mousemove 钳制: [0, totalMinutes]（偏移分钟，不是 [minMinutes, maxMinutes]）
mouseup 输出: absStart = bMin + offsetMin（转为绝对时间）
pixelToMinutes 返回: 偏移分钟
```

### A2 三链加载锁模式
```js
var loadingRef = useRef({ header: false, main: false, sub: false });
async function loadChain(name, fn) {
  if (loadingRef.current[name]) return;
  loadingRef.current[name] = true;
  try { await fn(); } catch (e) { addLog("["+name+"] fail: " + (e.message || e)); }
  finally { loadingRef.current[name] = false; }
}
```

### A3 视图 ID 获取优先级
```
关联工作表: viewId = getRelationOpenView(cid) || getViews(ws)[0].viewId
当前工作表: viewId = config.viewId
```

```
1. c.defaultValue → JSON.parse → extractRowid(type29) / 多选合并 isDefault options(type10)

3. c.options[].isDefault → key
```

### A5 拖拽/拉伸 cleanup 模式
